# CampusPlanner 📚

CampusPlanner is a simple and interactive student productivity web application designed to help students manage their academic activities efficiently. It allows users to organize subjects, track assignments and exams, manage quick notes, and monitor study progress — all in one place.

---

## ✨ Features

### 📖 Subject Management
- Add subjects with subject codes and credits
- Organized subject table for easy tracking

### ✅ Task Management
- Add assignments, exams, and study tasks
- Set due dates and priorities
- Mark tasks as completed
- Track overdue tasks

### 📝 Quick Notes
- Create and manage personal study notes
- Store important reminders and information

### 📊 Dashboard
- View total subjects
- Track total tasks
- Monitor completed and overdue tasks
- Display current date and user greeting

### 👤 Personalized Experience
- Save user name
- Dynamic greeting section

### 🎨 Responsive UI
- Clean sidebar navigation
- Simple and modern design
- User-friendly interface
